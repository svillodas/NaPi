# NaPi
Análise, deseño e implementación dunha aplicación IoT real facendo uso de novas arquitecturas/paradigmas IoT.

Deseño dun sistema de detección de caídas para persoas con mobilidade reducida. Para esta solución detectaremos a caída da persoa mediante un acelerómetro, comprobaremos se a persoa esta dentro da súa vivenda mediante un sensor PIR e se mantén o pulso despois da caída. O sistema tendrá ademais un botón de pánico. Unha vez detectado, activarase unha alerta mediante un buzzer e un led.
